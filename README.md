## はじめに
- 本リポジトリは、開発者（PenguinPetra）自身が「本当に使いたい」という思いから開発された、日記アプリ「my-diary」に関するものです。
- 作成したアプリはこちら
https://my-diary-wheat.vercel.app/
- ご利用いただくことでのトラブル等は一切責任を負いかねます。
## コンセプト
- 「理想の追求が生んだ、日記の到達点」
- 世に溢れる日記アプリに満足できなかった開発者が、自らの理想とする「使いやすさ」と「利便性」を追い求め、幾度もの試行錯誤を重ねて辿り着いた答え。それが、この「my-diary」です。
- **感性に響く体験**：日記を開いた瞬間、当時の思い出が鮮やかに浮かび上がるような「懐かしさ」の演出
- **日常を豊かにする実用性**：日記という枠を超え、タスク管理機能の搭載
## アプリ概要
- 本アプリでは「日記の作成」、「日記の閲覧」ができるアプリです。
- さらに、タスク管理を行う「タスク日記」やフレンドと行う「交換日記」機能が搭載されています。
## 機能

機能説明では、特に開発において試行錯誤し、注力した箇所をピックアップして紹介します。

### **1. 直感的なアイコン作成機能**
ユーザーがアップロードした画像から、アイコンにしたい最適な位置を自由に調整できる機能を実装しました。
- **ユーザー体験（UX）の向上**：「react-easy-crop」ライブラリを採用し、ブラウザ上での直感的なドラッグ＆ズーム操作を実現しました。
- **技術的アプローチ**：ユーザーが選択した範囲の座標データをリアルタイムで取得。取得した座標を基に「Canvas API」を用いて、ブラウザ側（クライアントサイド）で画像の切り抜きおよびリサイズを実行しています。
- **パフォーマンスの最適化**：切り抜いた画像は最終的に軽量なBase64形式のデータへ変換してサーバーへ送信。これにより、不要なデータ通信を抑え、低速なネットワーク環境でもスムーズなプロフィール更新を可能にしました。

### **2. 思い出が鮮明に蘇る日記詳細画面**
記録した内容をただ表示するだけでなく、読み返した時に「その時の空気感」が伝わるデザインと機能を追求しました。
- **ビジュアル・ストーリーテリング**：アップロードした画像を画面上部に大きく配置し、一目で当時の情景が浮かび上がるレイアウトを採用しています。
- **心地よいユーザーインターフェース（UI）**：「Framer Motion」を活用した滑らかなアニメーションにより、詳細画面を開く際の「アルバムを手に取るような操作感」を演出。テキストのフォントサイズや行間にこだわり、長文の日記でも読み疲れしない可読性を確保しました。

### **3. 達成感をデザインするタスク日記作成と詳細画面**
「タスク管理」と「日記」を一つのインターフェースに統合することで、忙しい毎日の中でも無理なく記録を続けられる環境を構築しました。
- **進捗の可視化と自己管理**：「タイトル・締切・最終目標・今日の進捗・今後の予定」という項目を設けることで、漠然とした不安を具体的なタスクへ分解。現在の立ち位置を正確に把握できます。
- **心理的効果へのアプローチ**：締切や進捗を明文化することで、「適度な焦り」による集中力の向上と、完了時の**「大きな達成感」**を創出。モチベーションの維持をサポートします。
- **記憶の定着**：項目に沿って振り返りを行うプロセスが脳を刺激し、単に事実を羅列するだけの日記よりも、その日の活動が深く記憶に刻まれます。

### **4. 過去と現在を繋ぐカレンダー一覧機能**
直感的なカレンダーインターフェースにより、膨大な記録の中から「あの日の思い出」や「過去の成果」を瞬時に見つけ出すことができます。
- **一目でわかる記録の軌跡**：カレンダー上で日記がある日にドットが表示されるため、自分の継続の足跡を視覚的に実感できます。
- **スマートなアーカイブ選択（モーダル機能）**：同じ日に「思い出日記」と「タスク日記」の両方を記録していても、カレンダーをタップすると専用の選択画面が表示されます。
- **ユーザー体験（UX）の向上**：流れるようなアニメーションと共に、「どちらの日記を閲覧しますか？」と問いかける親切な設計により、迷うことなく目的の記録へアクセス可能です。

### **6. 大切な瞬間を逃さないリアルタイム通知機能**
交換日記の更新やフレンド申請など、アプリ内での重要な動きを視覚的なバッジ（通知ドット）で即座に知らせます。
- **直感的なインジケーター**：メニューアイコンの横に配置されたカラードット（オレンジや赤）により、画面を移動することなく「新しい情報の有無」を一目で確認できます。
- **能動的なコミュニケーションの促進**：相手からのアクションをリアルタイムに感じられるため、交換日記における「返信を書くワクワク感」を損なわせず、継続的な交流をサポートします。

### **7. 絆を深める交換日記機能**
デジタルでありながら、まるで本物のノートをやり取りしているような温かみのある体験を提供します。大切なパートナーや友人と、一対一の親密な対話を楽しむことができます。
- **本物の質感を再現した見開きデザイン**：紙のノートのようなマス目と、めくる楽しさを感じさせる見開きレイアウトを採用。
- **細部へのこだわり**：文字がマス目にぴったり乗るように設計されており（line-height: 40px）、デジタル特有の無機質さを排除した心地よい読書・執筆体験を実現しました。
- **「待つ」時間を楽しむターン制**：どちらか一方が書き終わるまで、もう一方は書くことができない「ターン制」を導入。相手が執筆中の間は「〇〇さんが書き終わるのを待っています...」と表示されます。すぐにレスポンスができるチャットツールとは一線を画す、相手を想い、返信を待つ「ゆったりとした時間」を演出します。
- **蓄積される二人の歩み**：書き溜めた日記はカレンダーからいつでも振り返ることが可能。二人の会話が、一冊のデジタルノートとして美しくアーカイブされていきます。また、数年後に見直したときの懐かしさUP！

## 開発環境
- 言語/フレームワーク： TypeScript、Next.js 15(App Router)
- UI/スタイリング：Tailwind CSS、Framer Motion(アニメーション)
- データベース/認証：Supabase(PostgreSQL、Auth、Storage)
- インフラ：Vercel
- 検証済みブラウザ：Google Chrome
## 利用方法
- 「はじめに」で記載したリンクにアクセスします。
- アカウント作成を行い、ログインします。
- 「+」ボタンをクリックすると、日記を作成できます。
- 「デイリー」をクリックすると、現在の時刻から近い順に表示されます。
- 「カレンダー」をクリックすると、日記がある日が青色になっています。クリックするとその日の日記を閲覧できます。
- フレンド機能は人のアイコンをクリックすると、使用できます。フレンド検索では、ユーザー名で検索することが可能です。片方が申請し、もう片方が承認すればフレンドになれます。
- 交換日記機能はbookアイコンをクリックすると、フレンドとのみ交換日記をすることができます。
